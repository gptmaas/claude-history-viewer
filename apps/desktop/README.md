# CodeMemory Desktop App

Target home for the personal local desktop app.

Planned responsibilities:

- Tauri app shell
- First-run local source detection
- Local-only settings
- Desktop menu/window integration
- Calls into `packages/local-engine` for file indexing and local pipeline execution

The root `package.json` already contains Tauri scripts, but the project does not yet have a complete `src-tauri` app shell. Add it here when desktop implementation starts.
