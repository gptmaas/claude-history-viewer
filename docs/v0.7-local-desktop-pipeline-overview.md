# CodeMemory v0.7 — 本地桌面版与自动化产品开发流水线

## Context

v0.6 完成用量分析后，CodeMemory 已具备会话采集、搜索、分析、分享和成本视角。v0.7 聚焦个人本地桌面版：把当前本地 Web Viewer 升级为打开即用的桌面 App，并在本地建立一条可追踪、可评审、可自动执行的 AI 产品开发流水线。

本主版本以 [local-desktop-pipeline-plan.md](./local-desktop-pipeline-plan.md) 为总纲，但拆分为多个可独立交付的小版本，避免一次性引入桌面打包、本地数据库、状态机、AI 执行器、测试和发布自动化带来的风险。

## 主版本目标

- 用户双击 App 后直接进入 Dashboard，无需手动启动开发服务。
- 默认支持本机 Claude Code 与 Codex CLI 历史数据。
- 本地数据从实时读文件演进为可增量索引、可快速查询的 SQLite 数据层。
- 新增“流水线”一级入口，把需求、方案、技术评审、开发、测试、验收、发布串成可追溯过程。
- 所有高风险动作默认需要人工确认，自动化能力逐步开放。

## 版本依赖

```text
v0.7.0 桌面 App MVP
  -> v0.7.1 本地索引与多数据源
    -> v0.7.2 流水线基础模型
      -> v0.7.3 方案生成与技术评审
        -> v0.7.4 自动编码与测试执行
          -> v0.7.5 集成验收与发布准备
```

v0.7.0 与 v0.7.1 是桌面产品底座；v0.7.2 是流水线数据底座；v0.7.3 开始引入 AI 生成和评审；v0.7.4 和 v0.7.5 才进入高风险自动执行与发布准备。

## 全局原则

- 本地优先：默认不依赖云端服务、登录或 API Key。
- 渐进自动化：先记录和评审，再执行和发布。
- 显式门禁：每个阶段必须有产物、状态、评审结论和事件日志。
- 证据驱动：AI 结论尽量绑定会话、diff、测试日志、截图和命令输出。
- 保守默认：删除、权限、发布、破坏性命令、远端推送等动作必须人工确认。

## 非目标

- v0.7 不实现团队协作版流水线。
- v0.7 不要求云端同步。
- v0.7 不把 CodeMemory 做成新的聊天入口。
- v0.7 不默认自动发布到远端仓库、应用商店或公开 release。
